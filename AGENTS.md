# AGENTS.md



## 1. Información general

- Los proyectos están desarrollados principalmente en Java 21.

- El nivel de programación debe adaptarse a un estudiante de DAM.

- Se debe priorizar un código sencillo, claro y fácil de entender.



## 2. Normas de programación

- Utilizar programación orientada a objetos.

- Separar las clases según su función.

- Utilizar atributos privados (`private`).

- Utilizar getters y setters cuando corresponda.

- Utilizar nombres descriptivos para variables, métodos y clases.

- Evitar repetir código innecesariamente.

- No complicar el código con soluciones demasiado avanzadas.

- Utilizar estructuras básicas de Java siempre que sea posible.



## 3. Forma de trabajar

- Respetar la estructura y los nombres de las clases existentes.

- No modificar partes del proyecto que no sean necesarias.

- No añadir librerías ni tecnologías nuevas sin necesidad.

- Mantener el código lo más parecido posible al estilo que ya utiliza el proyecto.

- No utilizar soluciones complejas si existe una alternativa más sencilla.



## 4. Explicaciones

- Explicar los cambios de forma sencilla y paso a paso.

- Indicar qué clases y métodos se han modificado.

- Explicar brevemente para qué sirve cada parte del código.

- Utilizar ejemplos cuando ayuden a entender el funcionamiento.

- Si se crea una clase nueva, proporcionar su código completo.



## 5. Restricciones

- Evitar patrones de diseño y técnicas avanzadas que no sean necesarias.

- No introducir programación compleja sin explicar previamente su utilidad.

- No eliminar funcionalidades que ya funcionan sin explicar bien y el porque de esos cambios.

- No inventar clases, métodos o atributos que no existan sin comprobar antes la estructura del proyecto.



## 6. Objetivo principal



El objetivo es desarrollar aplicaciones Java funcionales, organizadas y fáciles de mantener, utilizando los conocimientos propios de un estudiante de DAM.



El código debe ser sencillo, comprensible y permitir que el estudiante pueda entender cómo funciona y explicar su implementación.
